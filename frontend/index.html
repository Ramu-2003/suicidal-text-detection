Launch Prototype

Project Overview

This prototype explores classical ML approaches (TF-IDF + Logistic Regression) for detecting suicidal ideation signals in Portuguese text, using the Boamente dataset as benchmark.

Future iterations aim to integrate transformer-based models (e.g. BERT variants) for improved performance.

Important: This is not a validated diagnostic instrument. Predictions are experimental and should never replace professional mental health support.

Boamente Dataset

Purpose & Structure

Binary classification dataset from real Portuguese social media messages, manually annotated.

Core columns: id, text, target (0 = non-suicidal, 1 = suicidal)

Scale & Imbalance

  • ~15,000–20,000 non-suicidal entries
  • ~1,500–3,000 suicidal entries

Significant imbalance → Recall & F1 prioritized over raw accuracy.

Modeling Notes

  • Preprocessing: remove URLs/emojis, normalization, tokenization
  • Current baseline: TF-IDF + Logistic Regression
  • Threshold: models ≥85% validation accuracy only
